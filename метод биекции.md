Консольная программа на языке Python, реализующая численный метод бисекции

(деление отрезка пополам) для приближённого нахождения корня



Решает уравнение:

f(x) = x^3 - x - 2 = 0



На отрезке \[1; 2] с точностью eps = 0.0001.



Метод бисекции применим, если функция f(x) непрерывна на отрезке \[a; b]

и принимает на его концах значения разных знаков, f(a) \* f(b) < 0. Внутри отрезка гарантированно существует

хотя бы один корень



f(1) = 1 - 1 - 2 = -2 < 0

f(2) = 8 - 2 - 2 = 4 > 0



Знаки на концах разные --> корень существует



Программа печатает найденный приближённый корень и значение функции в этой

точке



Алгоритм:



Задать исходные данные:

Левая граница отрезка: a = 1

Правая граница отрезка: b = 2

Требуемая точность: eps = 0.0001

Проверить условие применимости метода: если f(a) \* f(b) >= 0, вывести

сообщение об ошибке и завершить работу. У нас f(1) \* f(2) = -2 \* 4 = -8 < 0 --> условие выполнено, можно

продолжать

Организовать цикл, который выполняется, пока длина половины текущего

отрезка больше заданной точности:

(b - a) / 2 > eps



Внутри цикла следующие действия:

Найти середину текущего отрезка: c = (a + b) / 2

Вычислить значение функции в этой точке f(c)

Сравнить знаки f(a) и f(c). Если f(a) \* f(c) < 0, то корень находится на левой половине

отрезка \[a; c], поэтому правую границу сдвигаем: b = c;

иначе корень находится на правой половине отрезка \[c; b],

поэтому левую границу сдвигаем --> a = c

Вернуться к проверке условия цикла

После выхода из цикла вычислить приближённое значение корня как

середину последнего отрезка:



x = (a + b) / 2



Вывести на экран найденное значение корня

Для проверки подставить найденный корень в исходную функцию и вывести

значение f(x), оно должно быть близко к нулю



Конец



Итерации прекращаются, когда длина текущего отрезка становится меньше

удвоенной точности (b - a) / 2 <= eps

Тогда любая точка отрезка отличается от

истинного корня не более чем на eps
